# RAJ — Core Integration

## Role

Core Integration Developer

## Responsibility

Responsible for integrating the different project modules and creating the main working application flow.

## Responsibilities

- Integrate the YOLO detection module with the application.
- Implement video-based vehicle detection.
- Implement live webcam detection.
- Implement vehicle counting.
- Display FPS and performance information.
- Connect the Image Processing module with the AI / YOLO module.
- Connect the detection system with the UI module.
- Manage the overall application workflow.
- Ensure that the different modules work together correctly.

## Module Output

- Integrated application workflow
- Video detection
- Live webcam detection
- Vehicle counts
- FPS/performance information
- Connected module outputs

## Integration

The Core Integration module connects:

Image Processing → AI / YOLO → Video/Webcam → Vehicle Counting → UI

It acts as the central connection between the different project modules.

## Technology

- Python
- OpenCV
- YOLO / Ultralytics
