# SANSKRITI — UI & Visualization

## Role

UI & Visualization Developer

## Responsibility

Responsible for designing and developing the user interface and visual presentation of the Vehicle Detection & Traffic Analysis system.

## Responsibilities

- Design and develop the project interface.
- Provide image selection functionality.
- Provide video selection functionality.
- Provide webcam input functionality.
- Display detection results.
- Display vehicle statistics.
- Visualize bounding boxes.
- Display detected vehicle classes and confidence scores.
- Create a clean and user-friendly interface.
- Present the output generated by the integrated detection system.

## Module Output

- Project interface
- Image/video/webcam selection
- Detection result display
- Vehicle statistics dashboard
- Bounding-box visualization
- User-friendly output presentation

## Integration

The UI module receives detection results from the Core Integration module and displays:

- Detected vehicles
- Vehicle classes
- Bounding boxes
- Confidence scores
- Vehicle statistics
- Performance information

## Technology

- Python
- OpenCV
- UI framework used by the project
- YOLO detection results
