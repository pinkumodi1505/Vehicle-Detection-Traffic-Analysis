# DEBANSHU — UI & Visualization

## Role

UI & Visualization Developer

## Responsibility

Responsible for designing and developing the user interface and visual presentation of the Vehicle Detection & Traffic Analysis system.

## Responsibilities

- Design and develop the project interface.
- Provide image selection functionality.
- Provide video selection functionality.
- Provide webcam input functionality.
- Allow the user to select a horizontal counting line for video processing.
- Display detection results.
- Display vehicle statistics.
- Visualize bounding boxes.
- Display detected vehicle classes and confidence scores.
- Display the selected counting line.
- Display FPS and processing status.
- Create a clean and user-friendly interface.
- Present the output generated by the integrated detection system.

## Module Input

The UI receives:

- Image, video, or webcam input from the user.
- Processed detection and counting results from the Core Integration module.

For video counting, the UI provides the user-selected horizontal counting-line position:

```python
line_y = 450
The selected line_y value is passed to the Core Integration module for processing.
Module Output

Project interface.

Detection result display.

Integration
The UI communicates with the Core Integration module.
UI → Core Integration
The UI provides:
line_y
for the user-selected horizontal counting line.
Core Integration → UI
The Core Integration module provides:
{
    "total_count": 6,
    "class_counts": {
        "car": 5,
        "motorcycle": 0,
        "bus": 0,
        "truck": 1
    },
    "fps": 20.7,
    "status": "completed"
}
The UI displays these results to the user.
The UI does not implement vehicle detection, tracking, or counting logic.
